# Changelog

## 1.1.0

- Added Buddy Chat for conversations with multiple buddies, including screen-name mentions and paced replies.
- Improved editable buddy memory and added controls for memory use and pinned facts.
- Added optional connected MCP services and per-buddy tool permissions, with Allow once and Always allow choices.
- Added tool calling for compatible Ollama models and OpenAI-style providers, including MiniMax.
- Improved the built-in Dial-Up Friends and character world settings.

## 1.0.0

- Released the first public version of AI Instant Messenger for Windows.
- Added an AIM-inspired buddy list, individual chat windows, profiles, presence, status messages, notification sounds, and human-paced replies.
- Added OpenAI, Anthropic, Google Gemini, MiniMax, OpenRouter, Ollama, OpenAI-compatible providers, and ChatGPT subscription sign-in.
- Added saved chat history, editable per-buddy memory, conversation transcripts, and local data backup and restore.
- Included four original Dial-Up Friends and support for importing and exporting portable AIIM character files with portraits.
- Added spontaneous buddy check-ins that respect the user's availability and each buddy's presence.
- Added provider connection tests, model discovery, reply cancellation and retry controls, automatic data recovery, and secure Windows credential storage.
- Added in-app help, notification-area controls, an optional uninstall data-removal prompt, and Windows release verification.
